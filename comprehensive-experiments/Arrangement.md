## 具体分工（单个模块、集成模块、数据组合、性能测试）
### 1. 唐知怡
用户账户相关

1. 注册模块 — 填写信息创建新账户，验证"ACCOUNT CREATED!"
2. 登录模块 — 用正确/错误的账号密码登录，验证登录成功或错误提示
3. 登出模块 — 登录后点击Logout，验证跳回登录页

### 2. 乔思齐
商品浏览相关

4. 商品列表模块 — 点击Products，验证商品列表页正常加载、商品卡片可见 
5. 商品详情模块 — 点击View Product，验证商品名、价格、分类、库存、品牌等信息可见 
6. 商品搜索模块 — 在搜索框输入关键词，验证搜索结果与关键词相关

### 3. 曹宇声
购物车相关

7. 添加购物车模块 — hover商品后点击Add to Cart，验证弹窗提示添加成功 
8. 购物车数量修改模块 — 在商品详情页修改数量后加入购物车，验证Cart中数量正确 
9. 删除购物车商品模块 — 在Cart页点击X删除商品，验证商品被移除

### 4. 沈徐鹏
辅助功能相关

10. 联系我们模块 — 填写Contact Us表单（姓名、邮箱、主题、消息、上传文件），验证提交成功提示 
11. 分类筛选模块 — 点击左侧栏Women/Men分类，验证对应分类商品页正确显示 
12. 订阅模块 — 滚动到页脚，输入邮箱订阅newsletter，验证成功提示

三个集成测试路径：

    1.多商品购物车（深度5）
    首页 → Women/Dress → 加购1 → Men/Tshirt → 加购2 → 验证购物车有2件

    2.搜索订阅（深度6）
    首页 → Products → 搜索"Summer" → 加购 → 订阅 → 验证成功
    
    3.品牌筛选删除（深度5）
    首页 → 品牌筛选 → 加购 → 购物车 → 删除 → 验证清空
